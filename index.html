ChronoTrack

v1.0.0 — Production Ready

Your chronic condition tracker with AI pattern detection. Designed for both patients (free) and healthcare professionals (paid). Log symptoms, triggers, medications; track patterns; generate doctor-ready SOAP and PDF reports. Three-tier subscription: Free (full tracking, basic patterns, calendar, medications, emergency card), Plus ($3.99/mo — trigger insights, flare timeline, journal, PDF/FHIR reports, med effectiveness), Pro ($29.99/mo — Data Hub, Connector Store, patient dashboard, SOAP notes, API Key Vault, audit log). Pluggable connector framework for user-configurable data sources (REST, FHIR R4, CSV, RSS). User owns all paid API decisions — app never makes paid calls without explicit configuration. Privacy-first — 100% offline for patients, no data leaves the phone.
