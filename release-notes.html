NutriSize is under active development. This page documents each production release with what changed, what's new, and what to expect.

These release notes are maintained by AI agents. While we strive for accuracy, limitations may apply.

v2.0.0 Stable Current March 2026

Major UI redesign with visual health intelligence. Collapsible content, color-coded range bars for 30+ clinical parameters, Simply Put (plain language) + Clinical (evidence-based) context, tappable citations from WHO/CDC/AHA/NEJM, per-food nutrient contribution, breadcrumb navigation, in-app Privacy Policy.

What's included

  • Complete UI redesign: home grid, section menus with submenus, gradient banners
  • Visual range bars for Blood Pressure, Heart Rate, Temperature, Glucose, O2 Sat, BMI, and 25+ more parameters
  • Simply Put explanations for farmers and families worldwide
  • Clinical context for doctors and health professionals
  • Tappable inline citations [WHO] [CDC] [AHA] [ADA] [NEJM] opening in-app with Reload/Close/Open in Browser
  • Nutrition Individualize: collapsible days/meals, macro progress bars, per-food nutrient contribution with %DV
  • Exercise weekly plans: collapsible days with authority guidelines
  • All submenus: Nutrition Types (Macro/Micro/Daily/Regional), Individualize (Vegan/Vegetarian/Non-Veg), Exercise Types (5 levels), By Age (4 groups)
  • Smart single-step back navigation with breadcrumbs throughout
  • In-app Privacy Policy under System
  • Content accuracy: Vitamin D 51+, sodium range, BMI Class II, activity factors corrected per WHO/IOM/KDIGO
  • One-time Purchase button for premium features (price from store)

v1.0.1 Stable March 2026

Multilingual Physiology — 8 languages serving 75% of the world's population, plus zoom scrolling and bug fixes.

What's included

  • 8-language support: English, Spanish, Hindi, Mandarin Chinese, Arabic, French, Portuguese, Bengali, Japanese
  • Auto-detects device language on first launch
  • Language picker (globe icon) in Physiology parameter detail views
  • 11,032 translated fields across 197 parameters
  • Translated fields: simplyPut, analogy, whenToWorry, interpretation
  • Zoom scrolling: drag to pan in all directions when zoomed in (iOS, Android, Web)
  • Fixed iOS Physiology crash from data type mismatch
  • Compact expanded view in All Parameters with summary chips and Full Detail link

Initial beta release of NutriSize — a health intelligence app for nutrition and exercise.

What's included
