# Header/footer rules for this repo (read before editing any page)
Every HTML page here carries the same EqualInformation header (`<nav>`) and sticky `<footer>`. Shared look = `style.css`; pages with their own full design (lifeos-*, resume, openwallet-safety) load `chrome.css`, GENERATED by `python3 build-chrome-css.py` (re-run after changing header/footer/brand rules in style.css). Menu/footer link lists and the wordmark markup are COPIED into each page: change them with a script over ALL `*.html`, then audit every file (new header `ei-word`, `#games` link, `footer-links`, `<footer`, css, toggle script). Separate sites under equalinformation.com (insurance-site, tools, ...) are different repos and keep their own branding. Full procedure and lessons: `SITE-CHROME.md` (this repo) and `~/coding_common/pvt/dotfiles/global-memory/site-chrome-change-checklist.md`.
